# Jo一個T9注音 隱私權政策

最後更新：2026 年 10 月 1 日

「Jo一個T9注音」（以下稱「本 App」）是 iPhone 上的 T9 注音鍵盤。本政策說明本 App 如何處理你的資料。

## 摘要

- **開發者不收集任何資料。** 本 App 沒有帳號、沒有廣告、沒有分析或追蹤工具，也沒有自己的伺服器。
- 你打的字、學習紀錄與設定都**只存在你的裝置上**（以及你自己選擇開啟的 iCloud 備份）。
- 只有在你**自行開啟 LLM 聯想並填入自己的 API Key** 時，本 App 才會把少量上文送到**你指定的 AI 服務**。

## 本機儲存的資料

| 資料 | 用途 | 存放位置 |
|---|---|---|
| 選字頻率、前後詞搭配、最近選過的詞 | 讓常用字排在前面、提供下一詞建議 | 裝置上的 App Group 共用空間 |
| 鍵盤設定（音效、震動、臨近鍵容錯、LLM 設定） | 套用你的偏好 | 裝置上的 App Group 共用空間 |
| LLM API Key | 呼叫你指定的 AI 服務 | 裝置 Keychain 與 App Group 共用空間 |

這些資料不會傳送給開發者。刪除本 App 即會一併刪除。

## 「允許完整取用」的用途

iOS 要求鍵盤開啟「允許完整取用」才能：

1. 讓鍵盤與主 App 共用設定與學習紀錄（App Group）；
2. 在你開啟 LLM 聯想時連線到你指定的 AI 服務；
3. 在你開啟 iCloud 備份時同步學習紀錄。

不開啟「完整取用」也能正常打字，只是上述功能無法使用。本 App 不會用「完整取用」記錄或上傳你的輸入內容。iOS 在密碼欄位一律改用系統鍵盤，本 App 無法讀取密碼欄位。

## LLM 聯想（選用，預設關閉）

開啟後，你在選字上屏時，本 App 會把**游標前最多 24 個字**的上文，連同你填寫的 API Key，直接傳送到你在設定中指定的服務網址（例如 OpenAI、Google Gemini、Groq 等 OpenAI 相容 API），以取得下一詞建議。

- 傳輸是從你的裝置**直接**連到該服務，不經過開發者的任何伺服器。
- 該服務如何處理資料，依該服務自己的隱私權政策與你和它之間的約定。
- 你可以隨時在 App 的「LLM」分頁關閉此功能或刪除 API Key。

## iCloud 備份（選用，預設關閉）

開啟後，學習紀錄（選字頻率、詞搭配、最近選過的詞）會存到**你自己的 iCloud 帳號**（iCloud 鍵值儲存），用於換機還原。開發者無法存取你的 iCloud 資料。你也可以改用「匯出 JSON」自行保存備份檔。

## 兒童隱私

本 App 不會蓄意收集任何人的個人資料，包括 13 歲以下兒童。
